ESTRUTURA
- assets/        -> visual e funcionamento (compartilhado por todos os prédios; não precisa mexer)
- modelo/        -> página-modelo. Para cada prédio, copie a pasta e renomeie (ex.: aguas-de-marco/)
- index.html     -> página da raiz (não lista os prédios)

PARA EDITAR UM PRÉDIO
Abra <pasta-do-prédio>/index.html e altere só o bloco "CONTEÚDO DA CARTILHA".
Tudo entre [colchetes] aparece em vermelho na página até ser preenchido.
